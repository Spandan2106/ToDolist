# Contributing to ToDolist

First off, thank you for considering contributing to ToDolist! It is people like you that make the open-source community such a great place to learn, inspire, and create.

## How to Contribute

### 1. Fork the Repository
Click the **Fork** button at the top right of the repository page to create a copy of this repository in your own GitHub account.

### 2. Clone the Repository
Clone your forked repository to your local machine:
```bash
git clone [https://github.com/your-username/ToDolist.git](https://github.com/your-username/ToDolist.git)****
