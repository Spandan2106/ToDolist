# ToDo List Application

A simple, lightweight web application to manage your daily tasks effectively, built using vanilla HTML, CSS, and JavaScript.

🚀 **Live Demo:** [ToDolist Live Site](https://to-dolist-phi-lovat.vercel.app/)

---

## Features

* **Add Tasks:** Quickly add new tasks to your list.
* **Mark as Complete:** Toggle tasks as done to keep track of progress.
* **Delete Tasks:** Remove unwanted or completed tasks easily.
* **Responsive Design:** Clean and accessible layout across desktop and mobile devices.

---

## Tech Stack

* **HTML5:** Structure and markup
* **CSS3:** Styling and responsive layout
* **JavaScript (ES6):** Dynamic logic and state management
